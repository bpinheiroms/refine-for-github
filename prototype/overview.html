What

The OpenCodeReview web page now opens only on the machine that runs it. Before, it was open to every device on the same network.

Why

The page hands the app's secret access token to anyone who opens it. So anyone who could reach the page could use the app, including on a shared office network or a server. The README already warned about this and told people to fix it by hand. A safe default is better than a warning.

How

The Docker setup now publishes the page on 127.0.0.1 by default. A new setting, OCR_WEB_BIND, lets people open it to other machines on purpose…
