# Translations

Strings live in `extension/_locales/<lang>/messages.json` (the WebExtension format).
`en` is the default locale and the only one with `description` fields — read them
before translating.

Placeholders are positional: `$1`, `$2`. Translations may reorder them, but every
placeholder of the English message must appear in the translation.

`GRLib.i18n.t(key, ...subs)` wraps `chrome.i18n.getMessage`. In tests, call
`setFallback(require(".../en/messages.json"))`. A missing key returns the key itself,
so an untranslated string is visible instead of blank.

The store description (`extDescription`) must stay under 132 characters in every locale.
